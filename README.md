# Habit Tracker

Simple Android habit tracker (Kotlin + Jetpack Compose).

- Add habits, tap to check off today
- 🔥 Current and best streaks
- Tap any of the last 7 days to fix missed check-ins
- Long-press a habit to delete it
- Dark mode + Material You colors (Android 12+)
- Everything is stored on your phone. No account, no internet.

## Install

Every push to `main` builds a new APK automatically:

**[Download latest APK](https://github.com/YatesV/habit-tracker/releases/latest/download/HabitTracker.apk)**

Open it on your phone and allow "Install unknown apps" if asked. New builds install over the old one and keep your habits.
